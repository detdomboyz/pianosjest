# Отдельное представление нот MelodiaJest

Версия компонента 0.1.0. TypeScript/React отображает подготовленные C4/D4/E4 в скрипичном и C3/D3/E3 в басовом ключе из `music-document v1`. Исходные ноты, ID, руки, пальцы и время не переписываются. Это открытый образец для разбора, без нового урока, подключения MIDI, звука, прогресса или облачного аккаунта.

Корневой тренажёр и `dist/web` остаются прежними. Этот пакет необязателен; его зависимости устанавливаются только внутри `web-reader`:

```powershell
npm --prefix web-reader install --ignore-scripts
npm --prefix web-reader test
npm --prefix web-reader run preview
```

Результат `dist/reader` — три статические страницы, CSS, локальный шрифт и лицензия. Показ только на loopback `127.0.0.1:4200`, без API. Порт можно задать через `MELODIA_READER_PORT`. Предпросмотр закрывается Ctrl+C.

В текущей среде сборка и проверки выполнены **без установки** через явно указанный уже установленный toolchain соседнего портала, только для чтения:

```powershell
node --preserve-symlinks --preserve-symlinks-main web-reader/tools/check.cjs --dependencies-dir C:/Users/Alexander/Documents/web/libre/node_modules
```

React/React DOM 19.3.0, TypeScript 5.8.3, типы React 19.1.8 / React DOM 19.1.3. Helper использует только библиотеки и не запускает код сборки, конфигурацию, БД, секреты или сервисы Libreta. Без `--dependencies-dir` ищет зависимости своего пакета. Чистая установка из registry в этой партии не проверялась.

## Границы компонента

`piano-staff-view.js/.d.ts` — чистая проекция документа и отдельного явного нотного написания, связанного с ID/версией/партией. Она не выводит энгармоническую запись из MIDI и не назначает руку по ключу. Начальный вид ограничен восемью нотами и шестью указанными высотами. Совместные ноты, удержанные голоса, неподтверждённое время, знаки и другие регистры дают явное ограничение. Если нельзя показать одну ноту, не рисуется сокращённая мелодия.

`src/StaffReader.tsx` получает только представление и необязательные назначения рук/пальцев соответствующей редакции. `idPrefix` задаётся вызывающей стороной и должен быть уникален для экземпляра. Компонент не импортирует архив каталога, не использует состояние/эффекты/DOM-измерения и не назначает новых ID нот. Нотная строка пока показывает **высоты**; ритмическая гравировка не заявлена. Время и пальцы доступны в нативном раскрываемом блоке.

Сборка проверяет строгие типы и использует настоящий `react-dom/server.renderToStaticMarkup`. В экспортированных страницах нет клиентского JavaScript и гидратации. Это проверенный React-компонент с отдельным локальным просмотром; Next.js-маршрут и полная миграция оболочки ещё не выполнены. В фактическом портале прочитаны Next.js 15.5.27 / React 19.3.0; служебная конфигурация не переносилась.

Bravura включён локально из официального репозитория Steinberg, без изменений, с полным OFL и хешем в `assets/SOURCES.json`. Текущая основная сборка не загружает этот шрифт или компонент.
