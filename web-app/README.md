# MelodiaJest: отдельная веб-практика чтения

Это локально проверенный ограниченный Next.js-экспорт **0.1.0**, рядом с основным тренажёром **23.5.23**. Настоящие маршруты: `/`, `/reading/treble/`, `/reading/bass/`. Они не заменяют каталог курса и произведений. Зарегистрированных новых уроков в этом пакете — 0.

Готовую сборку можно открыть без установки зависимостей: запусти `START-READING-WEB.cmd` из корня или `npm --prefix web-app run preview`, затем перейди на `http://127.0.0.1:4201/`. Сервер показывает только разрешённые файлы `dist/next`, слушает loopback и не включает API основного локального сервера. Текущие `START.cmd` / `START-WEB.cmd` сохраняются.

## Сборка и проверка

Пакет имеет собственный `package.json`. Для автономной разработки предусмотрена отдельная установка `npm --prefix web-app install --ignore-scripts`; чистая установка из реестра в этой партии **не проверялась**. Корневому тренажёру эти зависимости не нужны.

Проверенная сборка использует уже установленный Next.js 15.5.27, React/React DOM 19.3.0 и TypeScript 5.8.3 портала только для чтения:

```powershell
node --preserve-symlinks --preserve-symlinks-main web-app/tools/check.cjs --dependencies-dir C:/Users/Alexander/Documents/web/libre/node_modules
```

Помощник не запускает сборку/хуки портала и не читает его `.env`. Пишет только файлы текущего проекта. На этом Windows-хосте `Next.getProjectDir → fs.realpathSync` требует чтения метаданных родительского пути; штатная изоляция первоначально вернула EPERM. Фактическая сборка прошла с разрешённым расширением доступа инструмента. Зависимости не устанавливались, файлы соседнего проекта не менялись.

Проверки корня: `npm test`. Проверки открытого нотного компонента: `node --preserve-symlinks --preserve-symlinks-main web-reader/tools/check.cjs --dependencies-dir C:/Users/Alexander/Documents/web/libre/node_modules`.

## Что умеет практика

В каждом ключе шесть коротких шаблонов на трёх подготовленных высотах. Полная проверка 570 встроенных записей обнаружила все 12 шаблонов в опубликованной музыке: **новых для первой пробы сейчас 0**. Кнопка первой пробы отключена с объяснением; «Другая фраза для практики» меняет знакомый образец. У всех четыре атаки, один повтор и только соседние шаги. Рука и пальцы заданы отдельно от звучащих нот. Варианты не считаются самостоятельными уроками.

Политика банка v2 требует полного аудита исходного каталога; отсутствие или несовпадение доказательств блокирует построение банка. `npm run audit:reading-bank` сохраняет полные совпадения в документации. В клиент попадают только количества, ключи элементов и хеш встроенного корпуса, без исходных записей. Знакомство проверяется по точной непрерывной одноголосной последовательности высот в том же регистре; смена темпа, ритма, названия или руки её не освежает. Это консервативное правило проекта, а не правило оценивания RCM/ABRSM.

Новая запись появляется после сохранения показа и readback под общим Web Lock. До ответа нет названий, пальцев и ответных `data-*` в DOM. Раскрытие — явная практика. Описание хранит режим «Кратко / Развёрнуто / Скрыто» отдельно; во время первой пробы его нет в DOM независимо от настройки.

MIDI запрашивается только кнопкой, без SysEx и без использования выходов. Затем пользователь выбирает вход. Отключение/смена входа и прерывание отмечают практику. Экранные клавиши никогда не выдают первую MIDI-пробу. Нового автоматического звука в этом пакете нет; исходный звук основного тренажёра сохранён.

`music-reading-piano-v1` — отдельная история чтения. Её схема v1 и прежние результаты сохранены: обновление политики банка не сбрасывает показы и не сертифицирует задним числом старые «первые» ответы. Экспорт/импорт через JSON переносит журнал в пустое хранилище или повторяет идентичный импорт. Иная местная история не заменяется. Объединение двух различающихся журналов пока не реализовано. Старые ключи каталога, настроек и памяти не используются. Частные редакции, удалённая история, другие устройства и знакомство с музыкой вне сервиса неизвестны.

## Ограничения

Результат ограничен порядком высот: `executionVerified: false`. Не оцениваются ритм, паузы, пальцы, поза, педаль и художественное качество. Это не экзамен и не доказательство устойчивого навыка. Встроенные планы чтения не продвинуты в готовый курс: ещё нужны включение в учебный маршрут, связь с подготовками по ID, сохранность редакций/общего каталога и независимая музыкальная проверка.

Браузером проверены интерфейс, две вкладки, история на двух изолированных адресах, недоступное хранилище и 390 px. MIDI-порт проверен с инъецированными событиями/портами, без физического устройства и без открытия браузерного разрешения. Нативный blur/visibility в фоновом IAB не подтверждён как реальное пользовательское переключение; обработчик проверен на уровне контроллера. Полный каталог, удержанные голоса, аудио и прежний многоверсионный прогресс в Next.js ещё не перенесены.

`--opaque-origin-qa` у предпросмотра включает специальный CSP sandbox для проверки отказа хранилища. В обычном запуске его нет. Статические файлы проходят allowlist/HTTP-тесты; локальный preview не предназначен для публикации как сервер. Домен, DNS, хостинг и аккаунты не менялись.
