# MelodiaJest 23.5.270 на хостинге

Обновлены сайт и API. В курсе 687 учебных записей, из них 417 с MIDI-проверкой. На сайт вышли уроки «Правая отвечает басу в вальсе» и «Аккорд возвращается после тихой доли». Для обоих компонентов сохранена проверенная 23.5.268. [Новый урок](https://melodiajest.ru/trainer.html?lesson=detail-p-paired-waltz-shared-return-01).

- Сверены все 41 публичный файл, HTTPS, шесть контрольных сумм с рабочего компьютера, перенаправления 308 и 301, закрытые служебные пути, реестр 687 уроков и 289 позиций маршрута, ответ 304 по ETag. Сохранены 685 прежних редакций и схема PostgreSQL версии 2.
- В полном npm test прошли 3310 тестов, в целевом наборе 59. Прошли четыре аудита и 53 сервисных теста Windows с семью платформенными пропусками. В изолированном Linux прошли 46 выбранных проверок и семь проверок ограничений запуска. Восемь проверок HTTP-кэша прошли после подготовки временной файловой системы для тестовых данных. Сохранены 38 успешных результатов первого прогона и оба журнала настройки контейнера. [Отчёт курса](melodiajest-operations-2026-11-28-306.md).
- Во встроенном браузере на 390×844 px проверены два новых урока. У нового вальса видны обе паузы 625 и 1250 мс, в следующем кадре виден возврат аккорда. Разбор открывается Enter и закрывается пробелом с сохранением фокуса. Размер возвращён, временные вкладки закрыты. Аппаратный MIDI и педагогическая оценка остаются отдельными проверками.
- Архив содержит 1 731 выбранных исходников и 41 публичный файл, занимает 20 653 916 байт. Приватная копия на D: полностью прочитана и восстановлена. SHA-256 `0284d9aa6e199e8d366967ae701db510a1b252160f88a4de2ff2087ae5cd3169`. Исходный коммит `a8044e7d9b14d27571136e69f9de9c1d17ffb901` подтверждён на GitHub.
