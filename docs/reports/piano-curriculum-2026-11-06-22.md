Завершён длинный системный этап без отсечения на двадцатой минуте. **Новых уроков, пересмотров действующих уроков и новых планов — 0.** Основной релиз остаётся **23.5.23**. ## Конкретный результат

Работают настоящие статические маршруты `/`, `/reading/treble/`, `/reading/bass/` из `dist/next`. Это отдельная ограниченная практика чтения высот, не полный перенос курса. Для просмотра готовых файлов зависимости не нужны: **`START-READING-WEB.cmd`** или `npm --prefix web-app run preview`, адрес `http://127.0.0.1:4201/`. В конце проверки принадлежащие этапу серверы остановлены.

`piano-reading-bank.js/.d.ts` создаёт шесть фиксированных коротких шаблонов на ключ: четыре атаки, все три подготовленные высоты, один повтор, только соседние шаги. JSON-спецификация получает демонстрации и переносы непосредственно из двух планов; после их исключения остаются **четыре местных первых элемента на ключ**. Правая — C4/D4/E4 пальцами 1/2/3, левая — C3/D3/E3 пальцами 5/4/3. Назначения отдельны от звучащих нот. Варианты не увеличивают число уроков.

`piano-reading-controller.js/.d.ts` подключает проверенный автомат к React. Открытие новой записи записывается и подтверждается до показа. `openNext` выбирает следующий элемент внутри того же Web Lock, поэтому согласованные вкладки не резервируют один первый элемент одновременно. Ответ принимается до раскрытия; имена, пальцы, экранные клавиши, разбор и ответные `data-*` первой пробы отсутствуют в DOM. Сохранённый развёрнутый вид не открывает подсказки.

После явного раскрытия попытка становится практикой. Сброс, прерывание и повтор не возвращают первый статус. Экранный ввод никогда не выдаёт первую MIDI-пробу. Результат остаётся `pitch-order-only`, `executionVerified: false`: длительности, паузы, пальцы, поза, педаль и художественное качество не оцениваются.

`piano-reading-midi.js/.d.ts` запрашивает доступ только по кнопке, с `sysex: false`, затем пользователь выбирает вход. До этого ни порты, ни звук не открываются. Слушается только выбранный вход; смена/сброс/потеря входа отмечают прерывание, старые слушатели снимаются, принадлежащий компоненту порт закрывается. Проверены нулевая velocity, NoteOff, каналы, неверные байты, конкурирующие подключения и устаревшее асинхронное открытие порта. Физического инструмента в этой проверке не было. Нового автоматического звука нет; исходный звук тренажёра сохранён.

## История и удобство

Новая практика использует только `music-reading-piano-v1` и собственный `music-reading-ui-v1`. Старые ключи каталога, MIDI, настроек и памяти не читаются и не пишутся. Экспорт/импорт JSON переносит историю в пустое хранилище либо повторяет идентичный импорт; другая местная история не заменяется. Объединения разных журналов пока нет.

В настоящем браузере история с тремя показами, одним результатом практики и двумя незаконченными попытками перенесена между изолированными адресами 4201 → 4202. Обратный экспорт совпал полностью, включая ID, редакции, помощь и результаты. Импорт пустого журнала поверх неё отклонён, повторный экспорт остался прежним. Найдено и исправлено противоречивое сообщение об успехе при отказе; финальная Next-сборка и этот путь повторно проверены.

На отдельном 4203 с явным диагностическим CSP sandbox хранилище недоступно. Приложение показывает ошибку и оставляет знакомый образец, не открывая новый элемент и не сбрасывая историю. Обычный предпросмотр этот sandbox не включает.

Разбор сохраняет «Кратко / Развёрнуто / Скрыто»; скрытый блок возвращается тем же доступным select. Полный текст создаётся при раскрытии. На 390 px обнаружено обрезанное действие: теперь четыре строки краткого текста и отдельная строка «Развернуть разбор» остаются видимыми. Enter раскрывает, пробел сворачивает, aria-controls указывает существующую пустую область до раскрытия. После перезагрузки сохранённый скрытый/развёрнутый вид восстановлен. В первой пробе весь блок удалён независимо от настройки.

При viewport 390 × 844 фактические `clientWidth/scrollWidth` равны **376/376**, нотная строка помещается. Финальный снимок: [басовый ключ на мобильной ширине](../qa/piano-2026-11-06-22-reading-mobile.png); также сохранён [скрипичный ключ](../qa/piano-2026-11-06-22-first-reading.png).

Устаревшие принадлежащие сборке файлы удаляются только после проверки пути и прежнего хеша, пользовательские изменения не стираются.
