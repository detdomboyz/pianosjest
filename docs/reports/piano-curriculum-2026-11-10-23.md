## Связка A–B♭–C–D без повторного C

Прежняя заготовка research-p-f-major-bimanual-crossing-link-01. Ручной протокол подготовлен; исполнение не наблюдалось.

1. A3–B♭3–C4–D4 слева3–2–1–3.
2. A4–B♭4–C5–D5 справа3–4–1–2.
3. На C обе руки играют большими1 один раз.
4. Четверти0–3, отпусканиеу4; внутри паузы нет.
5. Проверь обе линии; при трудности вернись к короткому стыку.

Полный разбор:

1. Сначала обратись к двум коротким ручным карточкам22: B♭–C и C–D. Выясни трудность конкретной руки, затем снова сыграй две партии вместе. Короткие карточки ещё не исполнены; их ID не встроены в маршрут и не открывают его автоматически.
2. Подготовь вход A3→B♭3 левыми3→2 и A4→B♭4 правыми3→4 по точным окнам black-left0/1 и right-connected0/1. Родственный E→F из course07-04 можно только вручную поднять на5полутонов; попадание на чёрную клавишу проверяется отдельно, автоматической транспозиции нет.
3. Начни медленно с B♭3+B♭4→C4+C5→D4+D5: на C один совместный вход1/1 и одна четверть, затем слева3/справа2 на D. Не складывай две пары с повторением общего C и не добавляй паузу между ними.
4. Верни перед стыком A3+A4 третьими пальцами. Получается одна связная последовательность четырёх созвучий, а не два отдельных успешных упражнения.
5. Считай «раз,два,три,четыре» для начал0/1/2/3. После четверти на D отпусти у4, на следующем «раз». Только после окончания отдохни и спокойно приготовь новый вход; не превращай возврат к A в ноту или нисходящую связку.
6. Если вход A–B♭ неудобен, вернись к его точной руке; если распадается B♭–C, к правой короткой карточке22; если C–D, к левой. Затем восстанови всю A–B♭–C–D без дублирования C.
7. Для медленного разбора можно выбрать темп ниже плановых44BPM. Это ручная подготовка с прежними нотами/четвертями/legato, не новая редакция, numerical grade или самостоятельная цель.
8. Выбери одну наблюдаемую деталь на короткий блок около3–5минут с отдыхом: например, один C без остановки обеих линий. Позже повтори всю связку отдельно; даже ощущение лёгкости в одной сессии не доказывает устойчивого переноса в гамму.

- Общий C4+C5 звучит одним совместным вступлением, по одной атаке на руку, одной четвертью; не повторяй C и не меняй палец на удержанном звуке.
- Между B♭ и C справа4→1, между C и D слева1→3; движения происходят на соседних переходах, а не одновременно.

Полный разбор:
