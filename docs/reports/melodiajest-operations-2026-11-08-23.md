Проверка отклоняет последнюю неуспешную или незавершённую попытку, standby, несовпадающие source/snapshot/digest/archive, неподтверждённый runtime и отсутствие полного recovery-proof. Часы сверки данных и реального восстановления независимы: локальная сверка не обновляет `restoredAt`. Читаются только ограниченные JSON собственного namespace; переходы через произвольные symlink/path запрещены. Отсутствие профиля у установленного API не считается отсутствием аккаунтов.

Проверка не читает БД, не скачивает архивы и не делает S3-запросов. Приватные данные браузера по-прежнему требуют отдельного экспорта.
