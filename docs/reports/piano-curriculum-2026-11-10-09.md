MIDI-пары57+69,58+70,60+72,62+74. Пальцы слева3–2–1–3, справа3–4–1–2. Интервалы в каждой линии1/2/2полутона; каждый вертикальный интервал — октава между руками. Это не октавный охват одной руки. Прежние44BPM/4/4/четверти/legato — проектные настройки. Четыре доли, отпускание у4 на следующем «раз», внутри пауз нет; отдельная конечная тишина не оценивается.

В коротких парах C завершает правое4→1 и начинает левое1→3. Здесь это **один и тот же C в течение одной доли**, по одному NoteOn/Off на руку. Простая запись подряд двух ядер дала бы B♭–C–C–D. Она добавляет повтор C и не соответствует исходному плану. Удержание C две доли также меняет план. Подмена пальца на удержанном C не требуется. В этом этапе выполнена разовая сверка конкретных четырёх шагов, не реализован общий merge/дедупликатор музыкальных нот.

Пауза2–4 принадлежит двум изолированным заготовкам. В связке у2 звучит C, у3 — D; переносить туда прежнюю паузу нельзя. После D упражнение останавливается: возврат D→A не является новым связным переходом. Между отдельными пробами можно спокойно восстановить положение; эта внешняя пауза не добавлена в музыкальные данные.

## Зачем связка после двух пар

Она проверяет перенос: после правого4→1 на B♭–C сразу подготовить левое1→3 на C–D, сохраняя один C, общий пульс и две линии. В изолированных парах исходное положение можно заново приготовить после остановки/паузы; здесь настройка второй смены должна появиться во время продолжающейся фразы. Это полезный составной контекст, но большая длина и новое начало не делают его третьим самостоятельным навыком.

Перед связкой нужны обе подготовленные пары с их короткими основами. Их исследовательские ID пока отсутствуют в runtime registry: формальные requires текущего плана неразрешимы для готового маршрута. Наличие source-only контрактов не равно выполненной подготовке ученика. Даже успешные раздельные руки не доказывают совместную готовность.

Подготовка входа A→B♭ тоже явная. В существующем `course07-04` на индексах2/3 есть E3+E4→F3+F4 с теми же ролями3/3→2/4 и полутоном в обеих линиях. Ручной перенос+5 даёт A3+A4→B♭3+B♭4. **Исходные E/F белые, целевые B♭ чёрные**: совпадение интервала и пальцев не доказывает удобство новой поверхности. Поэтому дополнительно взяты точные одноручные A3/3→B♭3/2 из `detail-p-black-position-left-01` и A4/3→B♭4/4 из right-connected. После их краткой проверки нужно вернуться к совместному входу. Новую одноручную или отдельную транспонированную запись не создавали.

## Будущий текст карточки

Краткая часть — пять смысловых строк; UI не изменён:

1. Сыграй A–B♭–C–D: левая3–2–1–3, правая3–4–1–2.
2. Начни с A3/A4 третьими; на B♭ слева2, справа4.
3. На C обе руки играют большим1 один раз; сразу готовь D/3 слева и D/2 справа.
4. Считай «раз,два,три,четыре», отпусти на следующем «раз»; внутри фразы паузы нет.
5. Слушай обе линии; это перенос двух подготовленных переходов, автоматический зачёт связности пока не готов.

Медленный разбор: проверить обе короткие пары, затем B♭–C–D вместе через один C. Не переставлять пальцы после C и не заново нажимать его ради подготовки левой. Добавить только A перед этой трёхнотной связкой. Если вход на B♭ неудобен, отдельно проверить по точным коротким одноручным данным и возвратиться к двум рукам. Временное разбиение не получает зачёт полной фразы. При зажиме остановиться, восстановить свободное положение; удобство и реальные пальцы требует проверки человеком.

Слуховой образ: две линии в октаву, первый шаг узкий полутон, следующие два шире — целые тоны. C не повторяется и не растягивается, одна линия не обрывается ради движения другой. После последнего D общий спокойный конец. Известный образец — представление звука, не независимый слуховой тест. Новый аудиофайл не создан и не прослушан.

Ошибки: белая B вместо B♭; на B♭ одинаковые пальцы2/2 или4/4; после C левая идёт2 вместо3; правый D берётся3 вместо2; C звучит дважды/две доли; вставлена пауза перед D; прежний C зажат поверх D; D→A превращён в новый непрерывный скачок; кисть силой фиксируется. Самопроверка: четыре общие атаки, пальцы по строкам, ровные четверти, отдельное слушание каждой линии и один C на руку.

Около3–5минут с остановками, отдыхом и возвращением. Начало с B♭ или C — временная вариация разбора, не новый урок. Немедленная проба и возвращение после перерыва/на следующий день — разные наблюдения. Перенос: позднее включить фразу в четвёртый существующий план полной F-октавы вверх; это составной контроль, не дополнительная моторная цель. Полная октава не обязательна перед этой связкой.
