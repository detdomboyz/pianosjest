# Измерено ограничение полной JSON-копии

8 ноября 2026. Каталог и семь отдельных значений сохранились в настоящем браузере. Но единая JSON-оболочка с этими строками получила `QuotaExceededError` даже одна в пустом localStorage. Native IndexedDB сохранила и прочитала все строки точно. Это измерение будущего формата копии, а не обнаружение потери личных данных. Публичная **23.5.57** и previous **23.5.56** не менялись; повторная выкладка не требовалась.

`tools/measure-browser-checkpoint.cjs` получает данные через исполняемый `catalogSnapshot()` в изолированном VM. Для повторяемости фиксируется только savedAt. Личные browser данные и trainer-content.json не читаются. Полные учебные материалы, прежние редакции, ноты, ритм, пальцы и порядок сохранены. Отдельное поле rhythm занимает около 3,05 МБ UTF-8; суммирование JSON-значений полей не является разбиением полной строки.

Синтетический сценарий содержит 664 валидные операции настоящего progress reducer для 166 MIDI-уроков, а журналы whole/fragment и transfer archive пустые. Это нижний сценарий, не прогноз многолетнего прогресса. Максимальная квота не искалась, filling loop не запускался. Умножение code units на два не выдаётся за расход квоты браузера. При отказе localStorage прежнее значение сохранилось. В IndexedDB дополнительно различены null и пустая строка, сохранён одиночный UTF-16 surrogate. Два ограниченных прогона дали одинаковый исход; power-loss durability не проверялась.

Медианы пяти Node-повторов: parse 26,34 мс, stringify 31,02 мс, gzip 46,92 мс, Brotli 40,82 мс. Node 20.15.1, Windows. [Полные измерения](../browser-checkpoint-measurements.json) содержат CPU/RAM и min/max; пиковая память не измерялась. Эти значения не доказывают ускорение устройства ученика или S3/CDN. Сжатие в приложение не включено; синхронные компрессоры работают только в диагностическом Node CLI.

[Контракт](../BROWSER_CHECKPOINT_CONTRACT.md) описывает точные persisted raw, текущую модель и recoverable pending как разные части. Полный согласованный снимок, typed complete/incomplete-кандидат, общий барьер и восстановление пока не реализованы. Новая неиспользуемая блокировка не объявляется защитой существующих writers; IndexedDB-транзакция назначения не делает атомарным чтение localStorage и памяти. Recovery-v2 по-прежнему не является полной копией MIDI-прогресса, VPS/S3 не покрывают личные browser данные.

Пройдены **999 из 999** общих тестов, **3 из 3** целевых и **16 из 16** после восстановления финального архива, без пропусков. Холодный тест начался без dist, собрал собственную временную web-копию и удалил её по allowlist; общий dist cache не требовался. Последующая сборка дала те же 28 публичных файлов. Первый полный прогон выполнен до отделения тестовой сборки, итоговый — после. Ошибки диагностического адаптера исправлены: challengeEligible читает state.lesson, read-only import API проверяет наличие storage capability, HTML builder добавляет web-runtime. Производственные алгоритмы и проверки не ослаблялись. Музыкальные аудиты повторно не запускались при неизменной музыке.

Computer Use подтвердил настоящий storage, кнопку 44 px, клавиатурный фокус и отсутствие переполнения. Свои значения и database удалены, вкладка закрыта, сервер и порт 63358 остановлены.
