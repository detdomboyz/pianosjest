# MelodiaJest · выпуск 23.5.220 · 21 ноября 2026

Опубликована [23.5.220](https://melodiajest.ru/) из проверенного коммита `030fd89add58bcf027ad4f1a60fe45021fa6afbc`. Сайт и API оставили 23.5.186 для отката. На сайте 638 уроков и 368 MIDI-испытаний. Этот выпуск сделал доступными ещё 57 ранее подготовленных уроков. Партия 256 остаётся последней учебной партией. Автоматизация на паузе.

## Проверка выпуска

- HTTPS, перенаправления, закрытые служебные пути и SHA-256 всех 41 публичного файла проверены. API ответил на гостевой запрос, отдал 638 редакций и сохранил 289 позиций зачётного маршрута. Все 581 ранее опубликованные редакции совпали целиком.
- Локальные 3043 проверки, 55 целевых тестов и четыре музыкальных аудита сверены по файлам этапа 256. Из каталога восстановленного артефакта на Linux прошли 22 теста. Первый прогон показал, что стенду требовалась временная папка. После добавления изолированной папки те же тесты прошли.
- Во встроенном браузере открыт [новый урок си мажора](https://melodiajest.ru/trainer.html?lesson=detail-p-b-major-prepared-paired-upper-turn-01). Разбор раскрылся по Enter и свернулся по пробелу с сохранением фокуса. В разборе отображены три ссылки на подготовку. Гостевая вкладка закрыта. Физический MIDI в этой проверке не использовался.
- Libreta, Praicer и Grigorova ответили 200. Caddy, таймеры, основа PostgreSQL и схема версии 2 сохранены.

## Восстановление

- Пакет на D: прочитан, проверен по размеру и SHA-256 и восстановлен в отдельную папку. Размер 20238920 байт, SHA-256 `b6930d73978b78ceb7225a8254c3e4208d93cd4b4fe8c4685af1f9444e829ec9`. Восстановлено 1575 файлов. Копии 23.5.186 и 23.5.100 сверены тем же способом. Полный checkout и браузерные личные данные в пакет не входят.
- PostgreSQL восстановлен из внешнего снимка `5ab1c8b879c730ec92d876aa624ff3c99176943d2ec6cc11229fe5cbac347520`. Изолированный вход, раздельный доступ двух синтетических пользователей, сохранение приватной записи и запрет DDL прошли. Рабочие тома не использовались. Миграция базы не потребовалась.
- Старый сборщик применял предел 16 МиБ для отдельного файла к готовому архиву выпуска, а внешний пакет превышал прежние 64 МиБ. Исправлены чтение целых архивов и суммарная проверка пакета. Нормы 16 МиБ на члена архива и 256 МиБ памяти службы сохранены. Суммарный предел внешнего пакета 128 МиБ. На точном исходном архиве и измерительном стенде пик RSS составил 255467520 байт. Сборка набора из точных копий при том же ограничении завершилась с пиком RSS 277024768 байт. RSS процесса и учёт памяти cgroup измеряют разные величины. На конечном наборе скриптов прошли 13 Linux-регрессий восстановления. Окончательный хеш журнала сверили при переносе доказательств на D: и записали отдельно от хеша первоначальной неудачной проверки стенда.
- Новый внешний статический снимок `6245ff823a3c8590e3532197060475b76e8ea6046f427cd9d10e3cc600213b88` прочитан и восстановлен штатным заданием. Проверены 23.5.220 и 23.5.186. Старая версия S3-инструментария и пять файлов настроек сохранены в проверенном архиве на D:. Проверка рабочих копий завершилась успешно. Штатный повтор запуска подтвердил новую копию после первоначального отказа по размеру. В рабочем запуске MemoryPeak достиг 268435456 байт при неизменном ограничении. Перед следующим выпуском с более крупным архивом нужен повторный замер пика.
- Откат 23.5.186 предусмотрен для пары API и сайта. В штатной процедуре версия API должна совпасть с проверяемой версией сайта. Производственный откат в этом выпуске не запускался.
