# MelodiaJest 23.5.268 на хостинге

28 ноября 2026 в 08:01:31 по Екатеринбургу опубликованы сайт и API. В курсе 685 учебных записей, из них 415 с MIDI-проверкой. В выпуск вошли «Вальс с паузой и новым басом» и исправление показа короткой паузы у тактовой черты. Для сайта и API сохранена проверенная 23.5.266. [Новый урок](https://melodiajest.ru/trainer.html?lesson=detail-p-paired-waltz-chord-to-bass-01).

## Проверки выпуска

- Проверены все 41 публичный файл. С рабочего компьютера сверены HTTPS, контрольные суммы изменённых путей, реестр из 685 уроков и 289 позиций маршрута, ответ 304 по ETag, перенаправления 308 и 301 с сохранением URI и закрытые служебные пути. Сохранены 684 прежние канонические редакции и схема PostgreSQL версии 2.
- На 390×844 px проверены два урока. В новом вальсе аккорд, пауза 625 мс в первом такте и G2 на следующем «раз» целиком внутри холста. В уроке левой руки пауза 313 мс появилась у конца первого такта. На обеих страницах ширина холста 285 px, горизонтальное смещение 0. Проверены три кнопки подготовки, раскрытие Enter, сворачивание пробелом, фокус и переход к последнему действию демо. Временные вкладки закрыты, обычный размер восстановлен. Аппаратный MIDI и педагогическая проверка остаются отдельными.
- В изолированном Linux прошёл 41 выбранный тест и семь проверок ограничений запуска. Локально прошли четыре музыкальных аудита, 53 сервисных теста Windows, семь платформенных пропусков. Общий `npm test` дал 3298 успешных и один сбой правила подготовки. После правки тестового кода два затронутых файла дали 49 из 49 успешных. [Отчёт учебного этапа](melodiajest-operations-2026-11-28-304.md).
- Архив выпуска содержит 1 720 выбранных исходников и 41 публичный файл, занимает 20 625 055 байт. Проверены полный SHA-256 `971ffbb7082774d4f497008df2de0637546592c40b651c512d257a29b87b2054`, чтение и восстановление на D:. Архив фиксирует проверенные исходники сборки до записи финальных отчётов. Исходный коммит `1956d3875ab060a05b0b4b903c2cdd09e024645f` проверен на GitHub.

- Снимок сайта `c6beff2e085657c755599e4c53aea33fd7d8c0b8fa80db51dfc0f2c25a8ba3b0` с версиями 23.5.268 и 23.5.266 прочитан, расшифрован и восстановлен. Обе версии запустились в изолированном Nginx. Часовая проверка попала в интервал, когда после смены API новая квитанция PostgreSQL ещё формировалась. После завершения копий и восстановления штатная проверка зелёная. Таймеры, ограничения запуска, Caddy и соседние сервисы сохранены. Календарное резервирование новой версии и полный биллинг S3 остаются отдельными наблюдениями. Штатные копии данных и используемые архивы сохранены. На D: временные файлы этой работы удалены, доступное место изменилось с 819 476 324 352 до 819 599 409 152 байт.
