# Исходная копия legacy-каталога

Статус 7 ноября 2026: `piano-legacy-catalog-copy.js` реализован и проверен изолированно; production-каталог не подключён. Публичная версия остаётся 23.5.47. Это подготовка к миграции, не выполненная миграция и не независимый бэкап личного браузера.

Модуль читает только `piano-blind-trainer-catalog-v1`. `prepareFrom(storage)` синхронно получает исходную строку до первого `await`, затем считает SHA256 вне транзакции. JSON не разбирается и не пересобирается: сохраняются пробелы, переносы, повреждённый JSON, NUL и одиночные суррогаты. Отсутствие ключа (`null`) отличается от пустой строки. Предел — 16 Mi UTF-16 code units; при превышении запись не начинается.

Проектное кодирование контрольной суммы: один байт присутствия (`0` для null, `1` для строки), затем каждый UTF-16 code unit в little-endian. Это собственный формат v1, не рекомендация W3C. Обычное преобразование в UTF-8 с заменой одиночных суррогатов потеряло бы различие между исходниками. `capturedAt` — метаданные, не часть ID. Наружу подготовка возвращает замороженные метаданные без строки; capability хранится в WeakMap и принимается только своим экземпляром.

База `melodiajest-legacy-catalog-v1`, версия 1, единственное object store `copies`. Запись содержит ровно `format`, `id`, `key`, `raw`, `codeUnits`, `capturedAt`. `commit(capability)` использует настоящую `readwrite`-транзакцию с `durability: strict`, проверяет существующую копию и число записей, затем выполняет `add`. Успех сообщается после `complete`. Четыре различных исходника — предел; пятый отклоняется. Автоматического удаления, вытеснения или перезаписи нет. Повтор того же исходника разрешён и при заполненной базе; дата первоначальной копии сохраняется. Конкурирующие соединения получают одну запись или явный отказ вместимости.

При abort/ошибке квоты новая запись не сохраняется, прежние остаются. `read(id)` завершает readonly-транзакцию, затем проверяет схему и SHA. Повреждённые и будущие записи не исправляются и не сбрасываются. `exportRecovery()` явно возвращает приватный JSON с исходными записями, включая неизвестную редакцию, которую нельзя использовать для миграции. Экспорт не скачивается и не отправляется автоматически. Непредставимые в JSON чужие данные дают ошибку экспорта с сохранением базы. `close()` запрещает новые операции; уже начатая транзакция может завершиться.

Копия подтверждает строку в момент чтения. Между localStorage и IndexedDB нет общей атомарной транзакции: прежний writer может изменить источник во время SHA или после commit. Перед реальной миграцией контроллер обязан повторно сверить исходник, согласовать конкурирующие writers и проверить применение без потери редакций. Пока не переведены импорт, редакторы, удаления, порядок и аппликатура, старый рабочий путь сохраняется. Модуль не пишет и не удаляет legacy-ключ, прогресс или настройки, не включает сеть, MIDI, звук и устройства. Его нет в allowlist публичной сборки.

Копия в той же области хранения браузера может исчезнуть вместе с ней. Переносимый экспорт и проверка его восстановления — отдельная пользовательская операция; VPS/S3 не содержат личного прогресса. Проверки этой фазы используют исключительно синтетические строки на отдельном localhost-origin. Настоящий пользовательский каталог не читался и не копировался.

Проверки: восемь Node-тестов на входы, точное кодирование, capability и асинхронные границы; strict TypeScript; 13 сценариев с native IndexedDB (гонки двух соединений, ёмкость, настоящий abort, внедрённая ошибка квоты, повреждение, будущая схема, переносимый синтетический цикл). Дополнительно вкладка действительно закрыта, создана новая по сохранённому адресу, прочитана точная строка с суррогатом/NUL, удалена только собственная QA-база. Enter, Space и 390×844 проверены. Реальное исчерпание диска, отключение питания и чужие браузеры не проверялись.

Прочитанные первоисточники 07.11.2026:

- [WHATWG Web Storage, getItem](https://html.spec.whatwg.org/multipage/webstorage.html#dom-storage-getitem): возврат значения либо null; строка не требует корректного JSON.
- [Web IDL §2.13.17 и §3.2.10 DOMString](https://webidl.spec.whatwg.org/#idl-DOMString): допускает непарные суррогаты и сохраняет последовательность code units. Это основание сохранять строку точно.
- [W3C IndexedDB, commit transaction](https://w3c.github.io/IndexedDB/#commit-transaction): strict durability и событие complete; отсутствие общей транзакции с localStorage — ограничение архитектуры проекта.
- [Vercel Web Interface Guidelines](https://raw.githubusercontent.com/vercel-labs/web-interface-guidelines/main/command.md): семантические кнопки, видимый focus, live-статус и отсутствие горизонтального переполнения в QA.
