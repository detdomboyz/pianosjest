# Покрытие курса пианино

В каталоге реализовано **422** учебных записей, из них **158** с текущим контрактом MIDI-челленджа. Поля происхождения заполнены в **82** уроках; независимая редактура преподавателем не выполнена.

Целевой минимум — **1000 содержательных микроуроков**. Ниже — предварительный каркас на **1310 учебных мест**, а не готовые описания такого количества уроков. Каждый бюджет уточняется по отдельным целям, источникам и отсутствию дублей. Число учебных записей с направлением и подробным объяснением — **82**; остальные требуют отдельной редакции. Автоматическая стадия не доказывает полное покрытие навыка.
