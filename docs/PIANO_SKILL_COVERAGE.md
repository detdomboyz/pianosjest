# Покрытие курса пианино

В каталоге реализовано **610** учебных записей, из них **340** с текущим контрактом MIDI-челленджа. Поля происхождения заполнены в **313** уроках; независимая редактура преподавателем не выполнена.

Целевой минимум — **1000 содержательных микроуроков**. Ниже — предварительный каркас на **1310 учебных мест**, а не готовые описания такого количества уроков. Каждый бюджет уточняется по отдельным целям, источникам и отсутствию дублей. Число учебных записей с направлением и подробным объяснением — **313**; остальные требуют отдельной редакции. Автоматическая стадия не доказывает полное покрытие навыка.
