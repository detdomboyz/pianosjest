# Проектные навыки

Установлены 5 ноября 2026 по просьбе пользователя через штатный `skill-installer` из публичных репозиториев авторов, локально в `.agents/skills`. `find-skills` использован для выбора, а не как автоматическое разрешение установки любых плагинов. Это инструкции для работы агента, не библиотеки, включаемые в приложение, и не интеграции с чужими аккаунтами.

| Навык | Источник | Когда применять |
| --- | --- | --- |
| find-skills | [Vercel Labs / skills](https://github.com/vercel-labs/skills/tree/main/skills/find-skills) | Найти конкретный недостающий навык и проверить автора перед установкой |
| frontend-design | [Anthropic / skills](https://github.com/anthropics/skills/tree/main/skills/frontend-design) | Сначала направление, типографика, палитра и компоновка; затем реализация и просмотр |
| web-design-guidelines | [Vercel Labs / agent-skills](https://github.com/vercel-labs/agent-skills/tree/main/skills/web-design-guidelines) | Доступность, фокус, формы, длинный текст, узкий экран; перечитывать актуальные правила перед ревью |
| react-best-practices | [Vercel Labs / agent-skills](https://github.com/vercel-labs/agent-skills/tree/main/skills/react-best-practices) | Границы модулей, загрузка данных, размер кода и рендеринг при переносе в React / Next.js |

В этом этапе применены короткое превью, доступное раскрытие, сохранение выбора, отложенное создание полного текста и проверка реального мобильного переполнения. Навык React не означает, что всё приложение уже перенесено в React. Загруженные лицензии сохранены рядом с навыками. Каталог уже обнаружен средой проекта; инструкции также прочитаны непосредственно перед применением.

Актуальные [Web Interface Guidelines](https://raw.githubusercontent.com/vercel-labs/web-interface-guidelines/main/command.md) проверены 5 ноября 2026. Они используются как рекомендации для затронутого интерфейса с учётом русского языка и музыкальных действий, не как повод переписывать весь продукт за один проход.
