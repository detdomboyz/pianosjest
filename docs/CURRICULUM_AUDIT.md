# Учебная последовательность и честный зачёт — 4–5 ноября 2026

Проверены все **1 261 встроенный элемент**: пианино — 548 / 84 темы, электрогитара — 713 / 109. В обучении 400 + 456 упражнений, остальные 405 элементов — библиотека произведений. Проверка и расширение v23.4 описаны в [LESSON_REVIEW.md](LESSON_REVIEW.md). Проверка охватывает данные, порядок навыков и исполняемый код зачёта. Пользовательские редакции из файлов и браузерного хранилища в этот корпус не входят.

**Исходный каталог нельзя было считать последовательным, полностью проверенным курсом.** Нумерация отражала добавление версий и репертуара; успешное завершение часто означало только попадание в нужные высоты. Исправлены воспроизводимые ошибки и добавлен отдельный маршрут по навыкам. Педагогическая экспертиза всех нотных редакций ещё не выполнена: такой статус не выдаётся ни одному уроку автоматически.

## Что означает «челлендж»

Пианино имеет три режима: практика с подсказками, MIDI-челлендж, исполнение из памяти. Челлендж доступен для неизменённых 80 начальных планов с явными пальцами и точным учебным ритмом. Отпечаток музыкальных данных связывает результат с конкретной редакцией; изменение нот, ритма или пальцев снимает доступность прежней проверки. Старые редакции прогресса сохраняются в истории.

В челлендже нужны все ноты без ошибок, учебный темп, корректные вступления, паузы и отпускания. Нельзя получить результат ручной игрой мышью/клавиатурой ПК, отключением визуального счётчика ритма, медленным прохождением с последующим повышением ползунка или прослушиванием подсказки после начала попытки. Реальный темп фиксируется при первом событии. Первая нота задаёт начало пульса; точность вступления после внешнего отсчёта сейчас не измеряется.

Порог вступления — `max(90 мс, 22% доли)`; длительности — `max(130 мс, 30% длительности)`. Эти допуски и цель «три чистых повтора, один из памяти» — **настройки проекта**, а не мировой экзаменационный норматив. Они требуют последующей калибровки на настоящих учениках и разных MIDI-устройствах. Проверка отпусканий предназначена для текущих начальных упражнений, без педали и специальных видов артикуляции; её нельзя переносить без адаптации на staccato, педальную музыку и сложную полифонию.

Три чистых повтора дают отметку готовности к следующему шагу; отдельная отметка появляется после чистого исполнения из памяти минимум через 24 часа от первого чистого результата. Можно открывать и разбирать дальнейшие уроки свободно — приложение не блокирует занятия на сутки. Хранятся результаты конкретного инструмента, урока и версии; нет общего «навыка владения обоими инструментами».

В режиме памяти скрыты нотный холст, клавиатура, текущие и будущие подсказки, инструкция с последовательностью нот и текст следующей цели. Демонстрацию можно слушать до первой ноты. Это упражнение воспроизведения подготовленной фразы, **не независимый тест слуха**. Нельзя сделать вывод о развитии слуха только из количества повторов известного задания.

MIDI не показывает пальцы, посадку, свободу кисти и художественное качество звука. Одноголосный гитарный детектор не устанавливает выбранную струну и не подтверждает все звуки аккорда, глушение, штрих, bend или vibrato. Эти границы написаны в карточках уроков и итогах.

## Чего пока не хватает для полного курса

1. Независимая редактура пианистом и гитаристом: удобство каждого движения в указанном темпе, музыкальность фраз, корректность аппликатур и доступность маленькой руке. Для каждой редакции нужны имя проверяющего, версия, источник, варианты и дата.
2. Пианино: линии legato/non-legato/staccato и повторных нот со сменой пальцев добавлены в v23.4; ещё нужны подмена пальца на удержанном звуке, выделения голоса, педали, минорных гамм, обращений и чтения незнакомого материала. Название старого упражнения не считается доказательством покрытия навыка.
3. Гитара: оценка отдельных атак и длительностей на музыкальной шкале, подтверждение аккордов, шума и глушения; отдельная калибровка bend/vibrato, настройки строя и выбора позиции. Нужна редактура 14 отмеченных MIDI-уроков, особенно White Swan, Oh Klahoma и The Slider.
4. Слух: новые короткие образцы для подбора, ритмическое эхо, интервалы и фразовые ответы с независимой проверкой. Прослушивание известного урока помогает заниматься, но не заменяет эти задания.
5. Калибровка трудности на учениках: ошибки, устойчивый чистый темп, время освоения, комфорт движений и удержание навыка через несколько дней. Только после этого расширять проверяемый маршрут за пределы текущих 136 MIDI-челленджей.

## Воспроизведение и границы проверки

```powershell
npm test
npm run audit:lessons
npm run audit:fingering
npm run audit:curriculum
```

Для проверки обоих каталогов рядом должна находиться папка `../guitarjest`. Зависимости npm не устанавливаются. Тесты исполняют реальные модули и обработчики приложений с изолированным хранилищем и часами. Есть регрессии ручного/ошибочного/просроченного гитарного результата, аккорда из отпущенных клавиш, неверных пауз, коротких удержаний, последнего отпускания, лишних нот в конце, памяти, смены редакции, флажолетов и широких позиций. Нулевой код `audit:curriculum` означает целостность карты и отсутствие необъяснённых изменений исходников; перечисленные ограничения от этого не исчезают.

При первоначальной проверке курса прошли **108 тестов**. После разделения обучения и произведений набор расширен до **116**, без ошибок и пропусков; подробности — [CATALOG_SECTIONS.md](CATALOG_SECTIONS.md). Общие модули маршрута, разделов и оценивания в двух приложениях дополнительно сравниваются побайтово.

В браузере использованы отдельные loopback-серверы: каталог пианино только в памяти, гитарные файлы только для чтения, запись в API и запуск Windows-дополнения запрещены. Проверены загрузка обоих маршрутов, скрытие подсказок в памяти, отказ в MIDI-зачёте при быстрых нажатиях ПК и завершение гитарного урока ручными отметками со статусом практики. [Пианино](qa/curriculum-memory.png). Гитарная проверка также включала подключённый редактор курса.

Настоящие MIDI- и аудиоустройства, техника рук, качество звука, реальные сутки между занятиями и эффект обучения на учениках в этой сессии не проверялись. Отсроченная логика проверена управляемыми часами. Резервные копии изменённых гитарных файлов сохранены в `pianosjest/tmp/guitar-before-curriculum-*`; пользовательские курсы, настройки и прежний прогресс не перезаписывались.
